# Agent CAD gallery handoff

## Scope

The current gallery is generated by `homepage/build.mjs` and controlled by `homepage/interactions.js`, at `/#project-agent-cad-local-modeling-workflow`. The former project detail route redirects to this anchor; `src/components/cad-gallery*` is retained legacy code, not the served homepage. The shared `@google/model-viewer` 4.3.1 bundle and selected GLB load only after the visitor clicks Load 3D model. The catalog contains the GT Partscaster, Les Paul study, and Bank of America Plaza · Atlanta exterior study.

The standalone gallery is `/demos/agent-cad/index.html`; `?model=boa` selects the Atlanta tower. The current homepage does not expose the legacy local-file preview control. The tower is a 1:1000 exterior study with documented 311.8 m height and estimated remaining dimensions/details, not an as-built reconstruction.

## Adding an approved model

1. Produce and verify a visual-only GLB derivative outside this repository; retain the CAD master and native verification artifacts in `/Users/nexus/code/agent-cad/`.
2. Create a poster and copy only the approved GLB/poster into `public/demos/<stable-id>/assets/`.
3. Add the model to `homepage/build.mjs` (selector and embedded poster), `homepage/interactions.js` (runtime catalog and SHA-256 revision), and the Agent CAD entry in `homepage/content.json`. Keep private source provenance out of public runtime assets. Keep the retained React catalog consistent, but do not mistake it for the active homepage.
4. Update `public/demos/agent-cad/index.html` and `viewer.js` if the standalone selector should include the new model.
5. Record exact SHA-256 and byte sizes with the project release receipt. Do not replace CAD masters with web derivatives.

## Validation

- `QA_URL=http://127.0.0.1:<port>/ node scripts/homepage-browser-qa.mjs` verifies the current homepage and all three models.
- `QA_URL=http://127.0.0.1:<port>/ node scripts/verify-boa-website.mjs` checks the tower standalone, dimensions, model switching, mobile fit, and blocked-GLB/error/retry on both surfaces. Receipts are under `.homepage-qa/`. Native Safari testing is separate.
- The standalone viewer switches to `loading=eager` only after a load click: manual reveal plus automatic loading otherwise waits behind its own poster. Errors restore the poster; retries change the URL.
- `scripts/verify-cad-gallery.mjs` targets the retired React gallery and is not a release gate for the current homepage.
