# Homepage migration

The production homepage is the approved standalone export in `homepage/`. Its canonical inputs are `content.json`, `theme.css`, `interactions.js`, and `build.mjs`; the build embeds the approved images from `public/` and writes `homepage/index.html`.

`npm run build` regenerates that HTML before running the Next.js production build. The root route serves the generated HTML as a static route handler, so deployment does not depend on the sibling `alternative/` directory.

The former V1 section and detail routes permanently redirect to the corresponding homepage anchors. Unknown project and publication detail slugs remain 404s. `/sitemap.xml` and `/robots.txt` are generated by Next.js for `https://portfolio.dakshhomelab.com/`.
